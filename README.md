# Catch Them Young (CaThY) 

**Catch Them Young (CaThY)** is a girls-in-STEM initiative founded to introduce children aged 8–14 to technology, building confidence and curiosity early, before the gap in representation has a chance to take hold.

## About

CaThY exists to close the STEM gender gap at its root. Rather than waiting until girls reach the age where they've already been steered away from tech, CaThY meets them young, when curiosity is naturally at its highest, and gives them hands-on exposure to technology in a fun, encouraging environment.

## Status

CaThY currently operates as a product under **TekkLab**. It has a full suite of branded print and event materials supporting workshops and outreach activities.

## Roadmap

We're actively exploring the path to registering CaThY as an independent **Community Interest Company (CIC)**. This would allow CaThY to:

- Build its own identity separate from TekkLab
- Pursue funding and partnerships in its own right
- Expand its reach and programme offerings
- Operate with a governance structure suited to its social mission

# CaThY Career Sprint

An interactive career discovery game for ages 8–16, built with React, Vite, and Tailwind CSS.

**Catch Them Young (CaThY) x TekkLab**

## What it is

Players pick an avatar (no sign-up, no personal data), choose one tech role, complete a hands-on challenge during a "school app hacked" scenario, and unlock a Player Card with real career information.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Pages

| Route | Description |
|-------|-------------|
| `/` | Landing — intro, how it works, outcomes |
| `/how-it-works` | Detailed rules & privacy |
| `/roles` | Browse all five tech roles |
| `/play/avatar` | Pick your avatar |
| `/play/role` | Choose one role for this mission |
| `/play/brief` | Mission briefing |
| `/play/challenge` | Role-specific puzzle |
| `/play/results` | Unlocked Player Card |

## Privacy

- Avatars only — no names, emails, or accounts
- Progress stored in `sessionStorage` (clears when tab closes)
- Nothing sent to a server
